05HTML → 长图流程

Windows 本机已验证：先大高度截一次，再自底向上裁到真实高度。

Chrome headless 2 倍图

chrome.exe --headless=new --disable-gpu \ --disable-software-rasterizer --no-sandbox \ --hide-scrollbars --force-device-scale-factor=2 \ --window-size=430,5200 \ --screenshot="<绝对 Windows 路径>\full.png" \ "file:///<TEMP 下纯 ASCII 路径>/p.html"

Pillow 自适应裁剪：取右下角像素为背景色，自底向上逐行采样，RGB 差 > 40 视为内容，裁到内容行 + 40 px。

环境坑（照抄可省 2 小时）

  • 中文路径的 file:// URL 要编码 → 先复制到 %TEMP% 用纯 ASCII 文件名规避。
  • --screenshot 必须给绝对 Windows 路径。
  • Git Bash 里 save('/tmp/x.png') 会落到 C:\tmp\ 而不是 TEMP。
  • 只加 --disable-gpu 会偶发 GPU 报错 → 必须补 --disable-software-rasterizer --no-sandbox。
  • --window-size=430 曾被 Chrome 最小窗口宽度截断右侧 → 截图后务必检查右侧是否被切。
  • 裁剪阈值取 RGB 差 > 40；太小会把底部光晕当内容、多留约 500 px 空白。
  • 本工作区实测：python 为 3.13.14，已装 Pillow 13.0.0；无 py 命令。
