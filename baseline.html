怎么读这组数

体重只是刚过超重线，内脏脂肪等级仍在正常范围；真正需要处理的是体脂偏高与腹部脂肪。

计划据此把每日摄入定为 1950 kcal（TDEE 约 2230，缺口约 350），并要求每周累计 150 分钟 Zone 2 中等强度有氧 —— 减腰围的底线，不是可选项。

结论

减脂盯腰围，不盯体重。两周体重与腰围都不动时，摄入再降 150 kcal 或 每天多走 2000 步，不要同时砍热量又加训练量。

04力线传导

问题不是各自独立，而是一条自下而上的链。

足弓微塌→ 胫骨外旋→ 骨盆前倾 + 左提→ 腰椎右旋→ 高低肩

另一条独立的线

上交叉（头前引 + 圆肩）由久坐低头单独形成，所以课表里既有下肢力线专项（周四），也有上交叉矫正（周二），还有每天分散做的收下巴与门框胸肌拉伸。

05干预优先级

1 · 先做

降腹脂 + 纠正骨盆前倾

髂腰肌松解 + 臀 / 腹激活。周一 / 周四治骨盆前倾 + 臀肌无力，半跪姿髂腰肌拉伸是力量 A 日第一优先。

2 · 跟进

上交叉 · 骨盆左提 · 足弓

胸肌 / 上斜方肌拉伸 + 菱形肌 / 中下斜方肌 / 颈深屈肌强化；左侧腰方肌放松 + 左臀中肌激活；足弓做短足运动。周二治上交叉，周三治骨盆左提 + 足弓。

3 · 先确诊

侧弯与 O 型腿

先去康复科 / 骨科确诊再谈矫正。在未确诊前，训练只做「抗旋」如 Pallof Press，不做大幅度主动旋转负重。

06安全红线

每次海报必须带上，不可省略。

未确诊禁项

侧弯 / O 型腿

不做强力侧弯矫正、不绑腿、不做大幅度主动旋转负重；只做「抗旋」如 Pallof Press。

立即停训

麻木 / 放射痛 / 夜间静息痛

出现任一情况 → 立即停训就医，并写进当日海报红线。

降重量

肩前侧夹挤感

降重量，不是「练开了」；上肢推日一夹挤就改上斜俯卧撑。
