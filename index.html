01这份计划要解决的 4 件事

用户原始需求（2026-10-19）：“我会给你发一份我的身体数据和体态诊断报告我需要你进行一个专业的分析基于这个分析，给我提供一个合适且合理的身体锻炼计划加体态矫正计划，这个计划的内容要做的直观一点，看起来很美化这种，每天第二天要刷新今天的锻炼计划的时候，要收集我昨天的锻炼计划完成情况以及个人感受”

硬要求 1

基于真实数据

身体数据 + 体态诊断报告做专业分析，不是通用健身模板。

硬要求 2

双目标合一

「锻炼计划 + 体态矫正计划」写在同一套课表里。

硬要求 3

直观、美观

这是交付形态要求，后来落地为 860px 竖版深色 PNG 海报。

硬要求 4

每日回采

刷新时必须回采昨日完成度与个人感受；缺了闭环就不算完成。

一句话教训

这个任务真正的难点不是排课，是跨设备回采。用户在手机微信读回复，本地 HTML 打不开，所以任何增加回采摩擦的改动都会让闭环断掉。

BMI 只是刚超重，但腰围与腰臀比都已过线。减脂的主战场是腰围。

03三个分期，12 周

起点 2026-10-19（周一）。周次按日期连续计算，不因中断重置。

W1 – W4

松解唤醒期

目标：腰围 −1.5 cm。先松解再激活，把骨盆摆到中立位；第 4 周是减量周（容量 −40%）与复测点。

W5 – W8

力量减脂期

目标：腰围 −3 cm、体重 −3 kg。强度从 RPE 6 推向 8，力量动作 7–8。

W9 – W12

整合巩固期

把矫正动作整合进力量与有氧，靠 4 点贴墙验收；每 4 周仍按同条件复测。

周次怎么算

第 N 周 = floor((今天 − 起点) / 7) + 1，上限 12；本周第 D 天 = (今天 − 起点) % 7 + 1。

课次怎么定

由星期决定（0 = 周日 … 6 = 周六），7 天循环，不因中断重置。

减量周

每 4 周的第 4 周容量减 40%；2026-11-09 起是第一个减量周。

04干预优先级

自上而下的体态问题里，骨盆前倾是核心；侧弯与 O 型腿先确诊再谈矫正。

优先级 1

降腹脂 + 纠正骨盆前倾

髂腰肌松解 + 臀 / 腹激活。半跪姿髂腰肌拉伸是力量 A 日「今天最重要」的动作。

优先级 2

上交叉 · 骨盆左提 · 足弓

胸肌 / 上斜方肌拉伸 + 菱形肌 / 中下斜方肌 / 颈深屈肌强化；左侧腰方肌放松 + 左臀中肌激活；足弓做短足运动。

优先级 3

先确诊，再谈矫正

侧弯风险与 O 型腿风险先去康复科 / 骨科确诊；在此之前只做「抗旋」，不做强力矫正。

05一周 7 天怎么排

3 力量 + 1 力线专项 + 1 代谢循环 + 1 有氧恢复 + 1 休息。拉类总量约为推类的 1.8 倍，把肩胛拉回中立位。

06每日闭环：先回采，再调整

每天 05:15（GMT+8）刷新；没有身体反馈就不许加量。

每日运行 SOP

读历史

移植包 + 回采台账 + 自动化记忆 + 最近一次交付物，确认昨天有无运行记录、有无回采、连续零回采天数。

算今天

按起点算周次 / 本周第几天 / 星期，取对应课次，写明分期与执行版本。

回采昨天

在对话正文里问「昨天：完成度 / 一个针对性体感」「今天：完成度 / RPE / 哪里酸」。

依反馈调整

无回复 → 不加组、不加重量、不补课；有酸痛 → 降级或换动作；仅 100% + RPE≤6 + 连续达标才进加量台阶。

出海报 · 交付 · 收尾

生成 430px 深色 HTML → 860px 竖版 PNG，检查截图后交付，再追加台账、日志与执行摘要。

为什么回采只认「一行字」

用户在中国手机微信端阅读回复，本地 HTML 打不开；HTML 卡片里的勾选框只存在用户本机浏览器里，Agent 读不到浏览器 localStorage。

试过但无效：一键四档回采按钮、自动复制回采码到剪贴板、回采码导入导出。真实通路只有用户在对话里回一行文字 → Agent 解析 → 写入台账。

所以回采提问必须同时出现在对话正文和海报底部。

昨天：完成度 / 一个针对性体感
今天：完成度 / RPE / 哪里酸
例：昨天 100 / 臀有感 · 今天 80 / 6 / 肩前侧

07关键术语

以下释义均来自计划本身，只做归纳，不引入计划外的判断。

骨盆前倾

评估为中度，是核心问题；干预从髂腰肌松解 + 臀 / 腹激活入手。

上交叉

头前引 + 圆肩，由久坐低头单独形成；靠拉类强化与胸肌 / 上斜方肌拉伸矫正。

力线传导

足弓微塌 → 胫骨外旋 → 骨盆前倾 + 左提 → 腰椎右旋 → 高低肩。

抗旋（Pallof Press）

侧弯 / O 型腿未确诊前，只做「抗旋」，不做大幅度主动旋转负重。

短足运动

足弓干预动作，周四激活 10 次 ×3；要点是不屈脚趾。

RPE

计划中的强度刻度：矫正动作 5–6，力量动作 7–8；加量台阶要求 RPE ≤ 6。

Zone 2

中等强度有氧，每周累计 150 min；快走 / 骑行 / 椭圆机 35–40 min，能说话不能唱歌。

2-2 法则

同重量能多做 2 次 × 2 组 → 加重 2.5–5%。

回归版 / 加量版

连续 ≥3 天零回采 → 回归版「本周先不加量」；完成度 100% 且 RPE≤6 且连续达标 → 才进加量台阶。

减量周

每 4 周的第 4 周容量减 40%，重量不变；与「因疼痛降级」不是一回事。

CK1 / MS1

回采码 CK1|日期|完成度|RPE|精力|酸痛|感受；围度码 MS1|日期|体重|腰围|后脑离墙。

4 点贴墙

验收动作：靠墙站时后脑 / 肩胛 / 臀 / 脚跟四点贴合。

08安全红线（每次海报必带）

  • 侧弯 / O 型腿未确诊前：不做强力侧弯矫正、不绑腿、不做大幅度主动旋转负重，只做「抗旋」如 Pallof Press；先去康复科 / 骨科确诊。
  • 出现麻木、放射痛、夜间静息痛 → 立即停训就医。
  • 肩前侧夹挤感 → 降重量，不是「练开了」。
